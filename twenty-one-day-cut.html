The seven rules

Twenty-one days is enough to become genuinely employable in Resolve — but only if you spend the hours the right way. These rules are what separate this plan from watching tutorials for three weeks and retaining nothing.

Rule 01

Render something every single day

An unrendered day didn't happen. Even a 20-second test export forces you through the whole chain: timeline settings, audio levels, codec choice. The Deliver page should stop being scary by Day 3, not Day 18.

Rule 02

Drill before you build

Start each session with 20 minutes of pure mechanics — the same trim, the same shortcut, twenty times. Editing speed is muscle memory. You cannot think about story while hunting for the blade tool.

Rule 03

Keyboard first, mouse second

Set your keyboard preset to DaVinci Resolve (not Premiere or FCP emulation) on Day 1 and never change it. Learn the native map once. Every shortcut you internalise is a permanent speed dividend.

Rule 04

Use real footage, not your own

Download Blackmagic's free lesson media. It's professionally shot, properly logged, and it removes the biggest time sink for beginners: agonising over their own precious clips. Judgement comes faster on material you're not attached to.

Rule 05

Finish ugly, then fix

Always cut a complete rough pass end-to-end before polishing anything. Editors who perfect the first 30 seconds never finish. Structure first, frames second.

Rule 06

Time-box the checkpoint

Each day ends with a timed self-test. If you can't hit it, repeat that drill tomorrow as your warm-up. Speed under a clock is exactly what a job measures.

Rule 07

Keep a mistakes log

One text file. Every time something breaks — offline media, wrong frame rate, audio out of sync — write the symptom and the fix in one line. By Day 21 that file is worth more than any course.

Day zero setup

Do this the night before Day 1. It takes about ninety minutes, most of it downloading, and it removes every excuse from the next three weeks.

Software

Install Resolve, free version

The free build does everything in this plan except a handful of Studio-only features (noise reduction, some Fusion tools, above-UHD render). Download from Blackmagic's support page. If your machine is older, install the version your hardware can actually run smoothly rather than the newest.

Books

Download the free training guides

From the training page, grab the PDFs for The Beginner's Guide to DaVinci Resolve 20 and The Editor's Guide to DaVinci Resolve 20. Skim the Colorist and Fairlight guides in Week 3. These are the official certification textbooks and they're free.

Media

Pull the lesson footage

Each guide has a matching lesson-media download (several GB each). Get the Beginner and Editor sets before Day 1 so a slow connection never eats a study session. Also grab the free training-video project files.

Storage

Build the folder skeleton

One drive, one folder per project, always the same five subfolders: 01_FOOTAGE, 02_AUDIO, 03_GRAPHICS, 04_PROJECT, 05_EXPORTS. Never import from Downloads. Never import from a phone. This one habit prevents most offline-media disasters.

Preferences

Set it up once, properly

  • Keyboard preset → DaVinci Resolve
  • Media Storage → your project drive, not the system disk
  • Cache and gallery stills → fast local drive
  • Auto-save / Live Save → on, plus project backups on
  • Timeline default → 1920×1080, 24 or 25 fps, matched to your footage
Ergonomics

Two things worth buying

A cheap wired mouse with a real middle click, and headphones you already trust. A second monitor helps enormously but isn't required. Skip the Speed Editor and colour panels for now — learn the keyboard first; panels reward people who already know the software.

If your machine struggles: work in Optimized Media (Playback → Use Optimized Media if Available) and set Timeline Proxy Mode to Half or Quarter Resolution. Stuttering playback destroys editing rhythm and teaches you bad timing instincts. Fix it on Day 0, not Day 12.

Every day runs the same four blocks. The order matters: mechanics while you're fresh, creative work while you're warm, review while you're tired.

Compressed track

If you only have 90 minutes

Drill 15 · Learn 30 · Build 40 · Ship 5. Cut the Learn block's optional reading, never the Drill or the Ship. Expect to need 26–28 days instead of 21 — that's a fine trade, and far better than quitting at Day 9.

Intensive track

If you have full days

Run the standard three hours in the morning, then add a second Build block in the afternoon on a different project — ideally something close to the work your new job will actually ask for. Do not add more Learn. More reading is not the bottleneck.

Assembly — get footage in, get a cut out

By Sunday you will have edited and delivered a complete short film. It will not be good. It will be finished, which at this stage is the only thing that matters.

01:00:00:00

Cold open

Edit3h 00

Install, configure, import, cut, export — all of it, today. You will make a bad 60-second edit within three hours of first launch, and that single loop removes 80% of the intimidation.

Drill 20m

Launch Resolve, create a project, delete it. Repeat five times. Learn the Project Manager cold: create, rename, export a .drp, import it back.

Learn 45m

Beginner's Guide, Lessons 1–2. Tour the seven pages and learn what each one is for. Memorise Shift+1–7 to jump between them.

Build 90m

On the Cut page only: import the lesson media, drop clips to the timeline, trim the heads and tails, add one music track. Sixty seconds, no titles, no effects.

Ship 25m

Quick Export → H.264 1080p. Watch it on your phone. Write down three things that feel wrong — don't fix them.

CheckpointNew project → import → timeline → export, in under 10 minutes, without looking anything up.

Media management

Edit3h 00

Learn the Media page and the discipline that keeps a project alive. Every professional editing job is 30% organisation. Editors who lose media lose work.

Drill 20m

Import the same folder five times into five fresh projects, building the same bin structure each time, faster each round.

Learn 45m

Bins vs Smart Bins, clip attributes, metadata and keywords, scene/shot/take, Power Bins for shared assets, and how to relink media that's gone offline.

Build 90m

Organise a full lesson-media set: bins by type, keywords on every clip, colour flags for selects. Then deliberately break it — move the source folder — and relink it.

Ship 25m

Save a project template: your bin structure, timeline settings and render presets, ready to duplicate for every future job.

CheckpointGiven 100 unsorted clips, produce a fully organised, keyworded project in 20 minutes — and relink it after a folder move without panic.

The Cut page, at speed

Edit3h 00

Master Resolve's fast-turnaround room. The Cut page is how you'll survive a same-day deadline in your first month on the job.

Drill 20m

Source Tape review: scrub an entire day's footage as one continuous strip, marking In/Out on every usable moment. I O, nothing else.

Learn 45m

Dual timeline, Source Tape, Smart Insert, Append, Ripple Overwrite, Close Up, Sync Bin, and the Boring Detector. Learn what each of the smart edit buttons actually does to the timeline.

Build 90m

Cut a 90-second piece entirely on the Cut page, under a self-imposed 45-minute clock. Then cut it again from scratch in 30.

Ship 25m

Quick Export both versions. Compare them. The faster one is usually tighter — note why.

CheckpointAssemble a watchable 90-second rough cut from raw footage in 30 minutes flat.
04:00:00:00

Edit page anatomy

Edit3h 00

Move into the room you'll spend your career in. Three-point editing is the grammar of the craft — everything after this is vocabulary.

Drill 20m

Twenty three-point edits in a row: mark In/Out in the source, park the playhead, choose the track destination, F10. No dragging with the mouse, at all.

Learn 45m

Editor's Guide: timeline anatomy, track destination and auto-select, source vs timeline viewer, the five edit types — insert, overwrite, replace, place on top, append — and JKL transport.

Build 90m

Rebuild yesterday's 90-second piece on the Edit page from scratch, using only keyboard edits. Add a second video track for cutaways.

Ship 25m

Export and A/B it against the Cut page version. Which was faster to make? Which is better? Write the answer down.

CheckpointExplain out loud what insert, overwrite, replace, place-on-top and append each do to surrounding clips — then demonstrate all five in 60 seconds.
05:00:00:00

Trimming — the real craft

Edit3h 00

Ripple, roll, slip, slide, and dynamic trim. This is the day amateurs skip and the day editors are actually made. Nothing else moves the needle this much.

Drill 20m

The trim ladder: take one edit point and perform all four trims on it in sequence, then nudge with , and .. Repeat across ten edit points.

Learn 45m

Trim Edit Mode T, Dynamic Trim W with JKL, asymmetric trimming, ripple delete, and why roll changes nothing about duration while ripple changes everything after it.

Build 90m

Take a dialogue scene from the lesson media and cut it properly: cut on action, trim every edit point deliberately, then tighten the whole scene by 15% without losing sense.

Ship 25m

Export the scene twice — before and after the 15% tighten — and watch both. The difference is the lesson.

CheckpointName which trim you need before you touch the timeline, every time, for ten consecutive edits.
06:00:00:00

Audio that doesn't embarrass you

Audio3h 00

Levels, sync, and split edits on the Edit page. Audiences forgive a soft image and never forgive bad sound. This is the cheapest quality win available to you.

Drill 20m

Build six J-cuts and six L-cuts. Unlink audio, extend the handle, listen. Do it until the shape is instinctive.

Learn 45m

Linked selection, syncing external audio by waveform or timecode, clip vs track volume, volume keyframes, audio track layers, and reading the meters instead of trusting your speakers.

Build 90m

Take yesterday's scene and do a full audio pass: level dialogue consistently, add room tone under every gap, place music under it and duck it beneath the voice.

Ship 25m

Export and listen on headphones, then on laptop speakers, then on your phone. Fix whatever falls apart on the worst one.

CheckpointDialogue sits at a consistent level, music never fights it, and no cut has an audible pop or dead silence under it.

Capstone I — The 60-Second Story

Deliver3h 30

One finished piece, made alone, no tutorials open. A complete small thing teaches more than a half-finished ambitious thing.

Brief —

Sixty seconds. A clear beginning, middle and end. One music bed, clean audio, no titles, no effects, no colour work. It must survive being watched twice.

Build 150m

Assemble → rough cut end-to-end → tighten → audio pass → picture lock. Give yourself one hour per pass and move on when the clock says so.

Ship 30m

Craft — decisions, not operations

Week 1 taught you to operate the software. This week is about what to cut and why, plus the three neighbouring skills every editing job quietly expects: multicam, motion graphics and a competent mix.

08:00:00:00

Story, pacing and where to cut

Edit3h 00

The theory that makes the mechanics worth something. Software knowledge gets you the interview; this gets you kept on.

Drill 20m

Cutting on action: find ten movements in the footage and cut mid-gesture on each. Then watch them back at speed and mark the ones that jump.

Learn 45m

Coverage and the shot hierarchy, the 180-degree rule, eyeline and screen direction, matching action, when a cut is motivated, and montage vs scene logic.

Build 90m

Re-cut one scene three separate ways: fast and aggressive, slow and observational, and with all dialogue removed. Same footage, three different films.

Ship 25m

Export all three back-to-back in one timeline and watch as a triptych. Note which choices came from the footage and which you imposed.

CheckpointFor any cut in your timeline, answer in one sentence why it happens on that exact frame.
09:00:00:00

Multicam and interviews

Edit3h 00

Two cameras, one conversation. Interview and event work is the bread and butter of most editing jobs — and multicam is how it gets done on time.

Drill 20m

Cut a five-minute multicam clip live at playback speed, switching angles by number key. Don't stop, don't fix. Then do it again.

Learn 45m

Creating multicam clips, syncing by timecode / audio waveform / in-points, cutting vs switching, refining angle changes after the fact, and using the Sync Bin for b-roll.

Build 90m

Cut a two-camera interview down to three minutes: remove every stumble and filler, hide each removal with a cutaway or angle change, keep it invisible.

Ship 25m

Export and watch specifically for jump cuts you failed to hide. Fix the worst two.

CheckpointTurn twenty minutes of two-camera interview into a tight three-minute cut in a single session.

Titles, motion and retiming

VFX3h 00

The Inspector, keyframes and speed. Lower thirds and a clean speed ramp are the two things you'll be asked for in your first week, guaranteed.

Drill 20m

Build the same lower third five times from scratch — Text+, position, font, colour, fade in and out — until it takes under two minutes.

Learn 45m

Text vs Text+, Fusion title templates, Inspector transforms, cropping, Dynamic Zoom, keyframes and the keyframe editor, retime controls, speed ramps and stabilisation.

Build 90m

Title package for your interview cut: an opening title, two lower thirds, an end card. Then add one speed ramp that actually serves a moment rather than showing off.

Ship 25m

Export and check title safe areas and legibility at phone size. If you can't read it on a phone, it's not finished.

CheckpointBuild a styled, animated lower third from scratch in under two minutes, and save it as a reusable preset.

Fusion, only what an editor needs

VFX3h 00

Nodes, masks, tracking, keying. You're not becoming a compositor this week. You're becoming the editor who can fix it instead of sending it out.

Drill 20m

Build the same node tree ten times: MediaIn → mask → Merge → MediaOut. Learn the node graph's navigation until it stops feeling foreign.

Learn 45m

How nodes differ from layers, the Merge node, masks and mattes, the Tracker and Planar Tracker, and DeltaKeyer for green screen.

Build 90m

Three practical fixes: remove a logo or blemish with a tracked patch, blur an unwanted face, and key one green-screen shot cleanly with a proper edge.

Ship 25m

Export a before/after split-screen of your best fix. This clip belongs in your reel.

CheckpointTrack an object and attach something to it that stays locked for the whole shot, with no slipping.

Fairlight — the mixing room

Audio3h 00

Dialogue that sounds professional. Most "cheap-looking" video is actually cheap-sounding video. Fix the voice and everything lifts.

Drill 20m

Take one noisy dialogue clip and repair it four different ways — EQ, dynamics, de-hum, level — listening critically to each in isolation.

Learn 45m

The Fairlight mixer, tracks vs buses, channel EQ, the dynamics section (compressor, gate, limiter), clip vs track levels, and recording voiceover directly into the timeline.

Build 90m

Full dialogue pass on the interview: even out levels, high-pass out rumble, gentle compression, notch out any hum, and remove the mouth noises that make edits feel amateur.

Ship 25m

Export audio-only and listen with your eyes closed. It should be effortless to follow.

CheckpointTake a rough, noisy dialogue clip and make it broadcast-listenable in under ten minutes.
13:00:00:00

Sound design and the mix

Audio3h 00

Layers, music and loudness. Sound design is how you make ordinary footage feel expensive.

Drill 20m

Take a silent 15-second clip and build its world from nothing: ambience, three spot effects, one movement sound. Then do a second clip.

Learn 45m

Track layering, cutting music to picture without wrecking the beat, ducking under dialogue, buses and submixes, and loudness — roughly −14 LUFS integrated for web, −23 LUFS for EBU R128 broadcast.

Build 90m

Complete mix of the interview piece: dialogue bus, music bus, effects bus, all routed properly, with a limiter on the main so nothing clips.

Ship 25m

Check your loudness meter against the target, export, and confirm on three different playback devices.

CheckpointDeliver a mix that hits its loudness target, never peaks into distortion, and needs no volume adjustment while watching.

Everything from Week 2, in one deliverable. This is the piece that proves you can hold a longer structure together.

Three minutes. Multicam interview, b-roll throughout, a title package, music, and a proper mix. Colour comes later — leave it ungraded on purpose.

Finish — colour, delivery and the professional habits

Resolve's reputation was built in the colour suite, and finishing is where editors who can also grade become far more valuable than editors who can't. This week also covers the unglamorous things that get you rehired: specs, versions, backups and revision rounds.

15:00:00:00

Primaries and scopes

Color3h 00

Balance a shot with your eyes on the scopes, not the image. Monitors lie. Scopes don't. This is the single biggest mindset shift in colour.

Drill 20m

Balance ten shots in ten minutes each cut to two: set black point, set white point, correct the cast. Scopes only, no artistic decisions.

Learn 45m

The node graph, serial nodes, Lift/Gamma/Gain vs Offset, contrast and pivot, and reading the waveform, parade and vectorscope confidently.

Build 90m

Balance every shot in your Capstone II timeline, then shot-match across the whole piece so it reads as one continuous camera.

Ship 25m

Export a before/after and check that skin tones sit near the vectorscope's skin line in both interview angles.

CheckpointBalance any shot to neutral in under 90 seconds using only the scopes to judge it.
16:00:00:00

Secondaries and look

Color3h 00

Qualifiers, windows, curves and a house look. Balance is technical and correct. Look is authored — and it's what a client actually notices.

Drill 20m

Isolate a skin tone with the qualifier and refine the matte until the edges are clean. Repeat on five different shots and lighting conditions.

Learn 45m

Serial ⌥S, parallel ⌥P and layer ⌥L nodes, HSL qualifiers, Power Windows with tracking, Hue vs Hue / Hue vs Sat curves, LUTs, and grade management with stills and versions.

Build 90m

Grade Capstone II properly: a vignette that isn't obvious, warmed skin, controlled background saturation, and a consistent look copied across every shot.

Ship 25m

Save the grade as a still to the Gallery and export a graded version alongside the ungraded one.

CheckpointBuild a look on one shot, then apply and adapt it across twenty shots in under 30 minutes.

Colour management and log

Color3h 00

Why the footage looked flat and grey. Understanding colour management is the line between someone who grades and someone who guesses.

Drill 20m

Take the same log clip and bring it to a correct Rec.709 image three ways: manually, with a conversion LUT, and with a colour-managed timeline. Compare all three.

Learn 45m

Log vs Rec.709, DaVinci YRGB vs colour-managed vs ACES, input/timeline/output colour spaces, camera raw settings, and where HDR fits in.

Build 90m

Ship 25m

05

Traps that cost beginners days

Each of these will happen to you at least once. Reading them now turns a lost afternoon into a five-minute fix.

My clips are offline / the media went red
You moved, renamed or unplugged the source files. Right-click the bin or clip → Relink Media and point at the new location. This is why everything lives in one project folder on one drive, imported from there and nowhere else — never from Downloads, never straight off a card.
Playback stutters and my timing instincts are ruined
Generate optimized media or proxies and enable Playback → Use Optimized Media if Available. Drop Timeline Proxy Mode to Half Resolution while cutting. Render Cache set to Smart handles heavier effects. Judge performance on the final render, not on laggy playback.
My timeline is a different frame rate than my footage
Set the timeline frame rate before the first clip lands — after that it's locked for the project. If it's wrong, create a new timeline at the right rate and copy your clips into it. Check Project Settings → Master Settings first, every single time.
Everything sounds quiet, or clips distort
Watch the meters, not the fader positions. Dialogue peaks around −12 to −6 dBFS, with the integrated loudness at your delivery target. Put a limiter on the main bus so nothing ever exceeds 0. If the source is distorted at record, no plugin will save it — reshoot or replace.
My export looks worse than the timeline
Usually bitrate or data levels. For 1080p H.264 aim for roughly 15–25 Mb/s; for 4K, considerably more. Check that data levels match between timeline and render, and that you haven't accidentally rendered a proxy-resolution timeline.
I clicked the wrong thing and the interface vanished
Workspace → Reset UI Layout. Learn this early; it's the fastest recovery in the whole application.
I applied a grade to one clip and it changed everything
You were on a shared node or an adjustment clip, or you had multiple clips selected in the thumbnail timeline. Check your selection before touching a wheel, and use versions to keep alternates.
My project crashed and I lost hours
Preferences → User → Project Save and Load: enable Live Save and Project Backups. Then export a .drp at the end of every session into 04_PROJECT. This is a five-second habit that has saved careers.

Day 22 — the job itself

What to do in your first week when the training wheels come off and the footage is real.

First hour

Learn their structure before their software

Ask where projects live, what the naming convention is, what specs they deliver, and who has the final say on a cut. Every studio's conventions differ more than the software does.

Version note

Books say 20, software may say 21

The training guides currently target Resolve 20 while the application ships ahead of them. Everything in this plan applies either way — menu locations shift occasionally, concepts don't.

One honest caveat: twenty-one days makes you a competent, employable operator with real finished work — it does not make you a senior editor. Taste takes years. But the mechanical fluency, the delivery discipline and the vocabulary all fit comfortably inside three weeks, and those are the things a new job tests first.
