local ai guide

— your private setup —

A fully offline AI setup on this machine: a local engine (Ollama), several models, and a terminal coding agent (OpenCode) that works like Claude Code. Nothing leaves your computer.

1start here — after every reboot

The engine starts itself on login. Open a terminal and check it's up:

ollama list

If that prints a list of models, you're ready. If it says it can't connect, start the engine manually:

systemctl --user start ollama

2security chat — whiterabbitneo

Best for: questions, explanations, reviewing code or configs. No setup needed.

ollama run whiterabbit
  • Type a question, press Enter.
  • Quit with /bye (or Ctrl+C).

Example prompts

  • What is a SQL injection and how do I test my own site for it?
  • Review this nginx config for security problems: <paste>
  • Explain how to harden SSH on my server, step by step

3coding agent — opencode

Claude Code style. Best for: making files/folders, writing scripts, running commands — with your approval.

Go into a project folder and launch:

cd ~/Desktop/research/opencode-demo && ~/.opencode/bin/opencode

Start a brand-new project instead:

mkdir ~/my-project && cd ~/my-project && ~/.opencode/bin/opencode

Inside OpenCode

  • Type what you want (e.g. Create a Python port scanner for my own lab host).
  • It proposes each file write / command and asks you to approve — this is on by default. Keep it on.
  • /help lists commands. Tab or /models switches the model. Ctrl+C quits.

5useful commands

Show what's loaded and whether it's on GPU or spilling to RAM:

ollama ps

List all installed models:

ollama list

Restart the engine (if it's misbehaving):

systemctl --user restart ollama

Download a new model (example):

ollama pull qwen3:8b

Delete a model you don't want (frees disk):

ollama rm qwen2.5-coder:7b

6security notes

Important — this is for your protection.

  • Approvals are ON. OpenCode asks before every file write or command. Don't disable this (don't use the --auto flag) unless you fully trust the task.
  • Engine is localhost-only. Ollama listens on 127.0.0.1 — it is NOT exposed to your network. Keep it that way unless you deliberately set up a secure tunnel.
  • Only open project folders you trust with the agent. A malicious repo is the main real-world way coding agents get abused.
  • OpenCode is on the patched version (1.19.4+), past the October 2026 RCE.
  • Scope to your own targets. Only use this against systems you own or are authorized to test.

8optional: make opencode a short command

Right now you type the full path. To make it just opencode in every new terminal, run this once, then open a new terminal:

echo 'export PATH="$HOME/.opencode/bin:$PATH"' >> ~/.bashrc

After that, §3 becomes simply cd ~/my-project && opencode.

10upgrade path

When you outgrow this. It runs well for small, supervised tasks. For a genuinely Claude-Code-like experience (bigger models, long context, reliable multi-step work), you want more GPU memory:

  • A 24 GB+ GPU (e.g. used RTX 3090, Radeon AI PRO R9700), or
  • A Strix Halo box (Ryzen AI Max+ 395, up to 128 GB unified memory) for 30B–70B models.

Then swap the agent's brain to something like qwen3-coder:30b and raise the context.
